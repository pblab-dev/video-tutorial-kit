# Catálogo de estilos de vídeo (20 modelos)

A página original com os previews e prompts de cada estilo é conteúdo de terceiros sem licença de redistribuição e NÃO faz parte deste kit. Aqui ficam só os nomes em português, o nível e a miniatura reduzida usada nos cards.

Nível para o nosso processo: R = rápido (2D no Remotion/SVG/Canvas), M = médio, L = mais lento (WebGL/3D/shaders).

Além destes, já temos nossos estilos próprios: 3D animado (argila/low-poly), 3D profissional (Blender), Curiosidade 3D humor A/B.

Nota: os prompts originais são para gerar HTML animado no Claude; para nós servem só como referência de direção de arte (cores, movimentos, tipo de cena). Nosso pipeline continua: roteiro -> narração aprovada -> animação -> render.
